# ABTalks Redesign

A mobile-first redesign of the ABTalks 60-Day Coding Challenge platform.

## 🗺️ Route Map

```text
/
/dashboard
/day/12
```

## ✨ Features

- 60-day coding challenge dashboard
- Daily challenge experience
- GitHub proof submission
- LinkedIn proof submission
- Streak tracking
- Challenge progress tracking
- Achievement system
- Daily reflection
- First-day state
- Missed-day recovery state
- Empty profile state
- Smooth micro-interactions and animations
- Mobile-first design optimized for 390px screens

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React

## 💡 Product Idea

The redesign focuses on helping students maintain consistency rather than feeling punished when they miss a day.

Students can clearly understand their progress, recover after a missed day, and start from zero without seeing an intimidating empty dashboard.

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
